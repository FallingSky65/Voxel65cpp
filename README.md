# Voxel65cpp

This is a program I wrote in the Summer of 2024, and it implements procedural terrain generation in a voxel engine inspired by Minecraft. It is written in C++ and uses [raylib](https://github.com/raysan5/raylib) (also [raylib-cpp](https://github.com/RobLoach/raylib-cpp) for cpp bindings) for graphics, and it implements on-the-fly optimized mesh generation.
